# Stage 9: actual-return learning versus one-step bootstrapping

Prospective registration 2026-11-18. Known evidence through Stage 8 and review of Yoo, Lee and Han (2023), https://doi.org/10.1007/s12469-022-00319-y. Question: does direct credit from realized remaining-day rewards improve this linear learner under the same 300-episode budget? This is an adaptation, not reproduction of that paper's gamma-zero/max-record procedure. No paper PDF committed.

## Fixed comparison

T: existing online normalized linear semi-gradient Q, alpha .001, gamma 1, equivalent to Stage 6. M: same linear model, every-visit episodic return regression. Collect a full 24-hour episode with weights and epsilon fixed during that day; keep exact-key diagnostic presence/visit counts at the same per-action point as T. Then compute G_t = r_t + G_(t+1), zero after actual day terminal, and perform one chronological pass over every visited transition: w[action_type] += .001*(G_t-Q(s_t,a_t))*phi(s_t,a_t). Every visit updated once; no averaging, shuffled passes, replay buffer, max-record, clipping, target network or importance weighting. Weights may change between these post-episode updates, so use the current prediction for each error; targets remain fixed realized suffixes. Hourly FINISH_PLAN does not terminate the return unless the whole day ends.

M is an on-policy, exploratory-policy return learner; T is an off-policy max-bootstrap learner. Thus the treatment changes target semantics, within-episode weight-update timing and policy evaluation/control relationship together. It does not isolate direct credit independently from those necessary changes. MC targets include exploratory future actions and may have high variance or give small/negative credit for poor continuations. This is not fitting oracle/reference-plan returns, not optimal Q supervision and not guaranteed stable/convergent. See Sutton and Barto, Chapter 5, https://web.stanford.edu/class/psych209/Readings/SuttonBartoIPRLBook2ndEd.pdf. No theoretical tabular convergence claim transfers to this finite-budget function approximator.

Hold fixed original 32 features and eight blocks/256 zero weights, q0=0, seven-field deadline-aware input, dense reward, data/assignment, action masks, 60-action hourly cap, fleet/routes/frequency bounds, original tie/RNG rules, alpha .001, gamma1. Epsilon uses original 300-episode schedule: 1 to .05 by 240 then .05. No priority rules, demonstrations, feature changes, new rewards or parameter search. Production defaults unchanged. Both retain exact-key audit dictionaries; unseen rates are novelty, not lack of learned guidance. Buffer one episode only for M; report measured RAM without claiming model-memory reduction.
